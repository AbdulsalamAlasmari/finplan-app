# مستقبلي المالي — منصة التخطيط المالي الشخصي

مشروع ويب كامل (Frontend + Backend + Database) يطبّق أفكار المشاريع التي أرسلتها:
حاسبة القيمة الزمنية للنقود، الميزانية وصافي الثروة، فحص القروض وضوابط ساما، عائد الاستثمار
ومعامل بيتا، والتحليل العقاري. كل أداة في صفحة مستقلة، بتصميم أبيض وأزرق.

---

## 1) بنية المشروع

```
finplan-app/
├── backend/                 ← الخادم الخلفي (Node.js + Express)
│   ├── server.js             نقطة تشغيل الخادم
│   ├── db.js                 طبقة قاعدة البيانات (ملف JSON، بدون تثبيت أي برنامج خارجي)
│   ├── routes/                نقاط الـ API لكل أداة (الميزانية، القروض، الاستثمار، العقار...)
│   └── data/db.json           قاعدة البيانات نفسها (تُنشأ وتُحدَّث تلقائياً)
│
└── frontend/                ← الواجهة (React + Vite)
    └── src/
        ├── pages/             كل أداة في ملف صفحة مستقل
        ├── components/        القائمة الجانبية والمكونات المشتركة
        └── index.css          نظام الألوان والتصميم (أبيض + أزرق)
```

**عن قاعدة البيانات:** بدل استخدام قاعدة بيانات تحتاج تثبيت برنامج منفصل (مثل PostgreSQL)،
استخدمت ملف `backend/data/db.json` كقاعدة بيانات بسيطة تُدار بالكامل عبر الكود في `db.js`.
هذا يجعل تشغيل المشروع فورياً بدون أي إعداد إضافي. كل مستخدم متصفح يحصل على معرّف عشوائي
يُخزَّن في متصفحه، وتُحفظ بياناته (ميزانيته، عقاراته، استثماراته...) منفصلة تحت هذا المعرّف.
لاحقاً إذا كبر المشروع، يسهل استبدال `db.js` بقاعدة بيانات حقيقية (PostgreSQL أو MySQL أو MongoDB)
دون تغيير أي شيء في الـ routes أو الواجهة.

## 2) تشغيل المشروع على جهازك (خطوة بخطوة)

### المتطلبات
ثبّت **Node.js** (نسخة 18 أو أحدث) من الموقع الرسمي: https://nodejs.org
تأكد من التثبيت بكتابة هذا الأمر في الطرفية (Terminal / cmd):
```
node -v
```

### الخطوة 1: فك الضغط
فك ملف `finplan-app.zip` في أي مجلد تريده على جهازك.

### الخطوة 2: تشغيل الباك إند (الخادم الخلفي)
افتح نافذة طرفية (Terminal) جديدة، وانسخ هذه الأوامر بالترتيب:
```bash
cd finplan-app/backend
npm install
npm run dev
```
إذا نجح التشغيل سترى:
```
✅ الخادم يعمل على http://localhost:4000
```
**اترك هذه النافذة مفتوحة** — الخادم يجب أن يبقى يعمل طول وقت استخدامك للموقع.

### الخطوة 3: تشغيل الفرونت إند (الواجهة)
افتح نافذة طرفية **ثانية** منفصلة (لا تغلق الأولى)، وانسخ:
```bash
cd finplan-app/frontend
npm install
npm run dev
```
سيظهر رابط مثل:
```
➜  Local:   http://localhost:5173/
```
افتح هذا الرابط في المتصفح — الموقع جاهز ويعمل بكامل أدواته.

> بهذا الشكل، أي تعديل تسويه على الكود في `frontend/src` يظهر فوراً في المتصفح بدون إعادة تشغيل.

## 3) وين تنسخ وتلصق الأكواد لو تبي تعدّل

| تبي تعدّل...                              | افتح هذا الملف |
|--------------------------------------------|----------------|
| الألوان (الأزرق، الخلفية...)               | `frontend/src/index.css` (أعلى الملف، قسم `:root`) |
| اسم المنصة أو الشعار في القائمة الجانبية    | `frontend/src/components/Layout.jsx` |
| نصوص الصفحة الرئيسية                       | `frontend/src/pages/Home.jsx` |
| معادلات أو حسابات أداة معينة (مثال: العقار) | `backend/routes/realestate.js` |
| إضافة أداة جديدة بالكامل                    | أنشئ ملف صفحة جديد في `frontend/src/pages/`، وأضفه في `frontend/src/App.jsx` و `Layout.jsx`، ثم أنشئ ملف route جديد في `backend/routes/` وسجّله في `backend/server.js` |

كل حاسبة (TVM, Budget, Loans, Investments, RealEstate) مستقلة تماماً في ملفها الخاص —
تقدر تعدّل واحدة دون التأثير على البقية.

## 4) نشر الموقع على الإنترنت (Deploy)

أسهل طريقة مجانية: **الباك إند على Render، والفرونت إند على Vercel**.

### أ. نشر الباك إند على Render
1. أنشئ حساب مجاني على https://render.com وأنشئ مستودع (repo) على GitHub يحتوي على مجلد `backend` (أو المشروع كامل).
2. من لوحة Render: **New → Web Service** → اختر المستودع.
3. الإعدادات:
   - **Root Directory:** `backend`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
4. بعد نجاح النشر ستحصل على رابط مثل: `https://finplan-backend.onrender.com`

### ب. نشر الفرونت إند على Vercel
1. أنشئ حساب على https://vercel.com واربطه بنفس مستودع GitHub.
2. عند الاستيراد، حدد **Root Directory:** `frontend`.
3. في إعدادات المشروع → **Environment Variables** أضف:
   - المفتاح: `VITE_API_URL`
   - القيمة: `https://finplan-backend.onrender.com/api` (رابط الباك إند من الخطوة السابقة + `/api`)
4. اضغط Deploy — ستحصل على رابط عام للموقع جاهز للمشاركة.

> ملاحظة: خطة Render المجانية "تنام" بعد فترة عدم استخدام، فأول طلب بعد فترة توقف قد يتأخر
> بضع ثوانٍ. هذا طبيعي ولا يؤثر على عمل الموقع.

## 5) مرجع سريع للمعادلات المطبّقة (من ملفاتك)

| الأداة | المعادلة |
|---|---|
| القيمة المستقبلية | `FV = PV × (1 + r)ⁿ` |
| القيمة الحالية | `PV = FV ÷ (1 + r)ⁿ` |
| الفائدة البسيطة | `I = PV × i × n` |
| ميزانية 50/30/20 | ضروريات 50% + كماليات 30% + ادخار 20% |
| صافي الثروة | الأصول − الخصوم |
| حد ساما الشخصي | الراتب × 33.33% (أو 25% للمتقاعدين) |
| قاعدة 28/36 | سكن ≤ 28% من الدخل، إجمالي التزامات ≤ 36% |
| العائد الكلي | العائد الجاري + العائد الرأسمالي |
| صافي الدخل التشغيلي (NOI) | الدخل الفعلي − المصاريف التشغيلية |
| العائد النقدي على النقد | (NOI − خدمة الدين) ÷ المبلغ الذاتي |
| نقطة التعادل العقارية | (المصاريف + خدمة الدين) ÷ الدخل الفعلي |

## 6) أفكار للتوسعة لاحقاً
- إضافة تسجيل دخول حقيقي (بريد إلكتروني + كلمة مرور) بدل المعرّف التلقائي.
- إضافة محاكي العرض والطلب (Market Equilibrium) كأداة سادسة.
- الانتقال من ملف JSON إلى قاعدة بيانات PostgreSQL عند زيادة عدد المستخدمين.
- ربط حاسبة الأصول بمصادر أسعار حية (أسهم، عقار) عبر API خارجي.
